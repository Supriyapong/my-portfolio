# My Portfolio

ที่ปรึกษาด้านการประเมินโครงการ (Feasibility Study) การร่วมลงทุนระหว่างรัฐและเอกชน (PPP) และเศรษฐศาสตร์พฤติกรรมประยุกต์ ของคุณสุปรียพงษ์ ตากรวด (คุณเปิ้น)

## 📁 โครงสร้างโปรเจกต์
- `index.html` - โครงสร้างหน้าเว็บหลัก (Semantic HTML5)
- `index.css` - ระบบดีไซน์สไตล์กระจกฝ้าพรีเมียม (Dark/Light Mode)
- `index.js` - ระบบตรรกะและการกรองข้อมูลผลงานโครงการ
- `assets/` - โฟลเดอร์เก็บไฟล์สื่อการนำเสนอ เช่น รูปภาพโปรไฟล์

## 💻 การใช้งานเว็บไซต์ในเครื่อง (Local View)
สามารถดับเบิลคลิกเปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์ใดก็ได้เพื่อดูการทำงานของหน้าเว็บทันทีโดยไม่ต้องใช้เซิร์ฟเวอร์ครับ
