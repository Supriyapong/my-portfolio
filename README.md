# My Portfolio

เว็บไซต์สองภาษาของสุปรียพงษ์ ตากรวด นักวิเคราะห์อิสระ นักเขียน และวิทยากร นำเสนอบทความคัดเลือก หัวข้อบรรยาย และประสบการณ์ด้านเศรษฐศาสตร์ การเงิน และการวางแผน โดยไม่เผยแพร่ข้อมูลเฉพาะของโครงการหรือ CV ที่แก้ไขได้

## โครงสร้างโปรเจกต์
- `index.html` - โครงสร้างหน้าเว็บหลัก (Semantic HTML5)
- `index.css` - รูปลักษณ์ Neumorphism และการจัดหน้าสำหรับมือถือ พร้อมธีมสว่างและมืด
- `index.js` - การสลับภาษา ธีม เมนู และสถานะฟอร์มติดต่อ
- `analytics.js` - Cloudflare Web Analytics เฉพาะเว็บที่เผยแพร่จริง
- `assets/` - รูปโปรไฟล์และภาพประกอบบทความคัดเลือก

## การใช้งานเว็บไซต์ในเครื่อง (Local View)
สามารถดับเบิลคลิกเปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์ใดก็ได้เพื่อดูการทำงานของหน้าเว็บทันทีโดยไม่ต้องใช้เซิร์ฟเวอร์ครับ

## ฟอร์มติดต่อและสถิติผู้เข้าชม

ฟอร์มส่งข้อความผ่าน HTTPS ของ FormSubmit และเก็บสถิติผ่าน Cloudflare Web Analytics เจ้าของเว็บยืนยันการรับข้อความทั้งสองภาษาและการดูสถิติแล้ว สถิติไม่แสดงสาธารณะ และไม่เก็บจากการเปิดไฟล์ในเครื่อง ดูขั้นตอนและข้อจำกัดใน [WEBSITE_SETUP.md](WEBSITE_SETUP.md)
